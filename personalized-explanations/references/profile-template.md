# Как собрать профиль

Профиль это короткий текст (до 10 строк) в форме инструкций для ИИ. Он должен работать в любом ассистенте, поэтому без названий инструментов и без слов о конкретных темах. Каждая строка опирается на вывод опроса или раунда.

## Из чего строить строки

| Вывод | Пример строки профиля |
|---|---|
| Опрос 1: только главное | Отвечай коротко, только главное. |
| Опрос 1: по делу, с примером | Отвечай по делу, без воды, средней длины, с одним примером. |
| Опрос 1: подробно | Объясняй подробно, с причинами. |
| Опрос 2: термины переводить | Термины переводи, оригинал давай в скобках. |
| Опрос 3: проверять вопросами | В конце проверяй понимание 2–3 вопросами. |
| Опрос 3: нет | Не проверяй понимание, пока не попрошу. |
| Опрос 5: только по просьбе / не надо | Заданий не давай, пока не попрошу. |
| Опрос 5: давать задания | После объяснения предлагай небольшое задание на практику. |
| Раунд 1: таблица | Для сравнения используй таблицу. |
| Раунд 1: схема-последовательность | Процессы показывай схемой со стрелками. |
| Раунд 1: аналогия | Объясняй через сравнение с обычной жизнью. |
| Раунд 1: не подошла аналогия | Бытовые аналогии не используй. |
| Раунд 1: пример с числами | Объясняй на конкретном примере с числами. |
| Раунд 1: не подошёл рисунок из символов | Схемы из символов не рисуй. |
| Раунд 2: от общего к деталям | Сначала картина целиком, потом детали. |
| Раунд 2: от примера к правилу | Начинай с реального примера, потом вывод. |
| Раунд 2: по шагам | Объясняй нумерованными шагами. |
| Раунд 2: список неудобен | Не используй длинные нумерованные списки для причин. |
| Раунд 3: коротко / подробно | Давай только главное. / Объясняй, почему так устроено. |
| Раунд 3: нравится реальный пример | Приводи реальный пример, на который можно посмотреть. |
| Раунд 4: вопросы и ответы | Строй объяснение как вопросы новичка и ответы на них. |
| Раунд 4: готовые вопросы читаются странно | Объясняй связным текстом, без заготовленных вопросов. |
| Раунд 4: по частям | Разбирай запись по частям слева направо, к каждой «что значит». |
| Раунд 4: было, стало | Показывай «без этого» и «с этим» рядом. |
| Раунд 5: другими словами | Если пишу «не понимаю», скажи то же проще, другими словами. |
| Раунд 5: другой формат | Если пишу «не понимаю», не повторяй теми же словами: смени формат. |
| Раунд 5: уточняющий вопрос | Если пишу «не понимаю», спроси, где именно я потерялся(-лась). |

Строки пиши от лица человека («пишу», «прошу»), без рода (используй «потерялся(-лась)» или перефразируй).

## Условные строки по типу темы

Если выбор в раундах зависел от типа темы, пиши строки с условием:

```
Для конкретных вещей (здания, события, предметы) приводи реальный пример, на который можно посмотреть.
Для технических и абстрактных тем (код, формулы) разбирай запись по частям слева направо и показывай шаги.
```

Если все раунды были про один тип темы, не придумывай условий: скажи человеку, что профиль проверен только на одном типе тем.

## Правила сборки

- Бери только то, что подтвердилось выбором в раундах или явным ответом в опросе. Не придумывай предпочтений.
- Если два варианта подошли, напиши условие: «для устройства чего-то таблица, для действий шаги».
- Добавь общие строки, которые не зависят от раундов: язык ответов, «примеры проверяй, а не пиши по памяти».
- Дай человеку прочитать и поправить текст до сохранения.

## Пример (условный)

```
Пиши по-русски, термины переводи. Отвечай по делу, без воды, с одним примером.
Начинай с реального примера, потом вывод. Главную мысль формулируй одной фразой.
Объясняй связным текстом, без заготовленных вопросов и длинных нумерованных списков.
Для сравнения используй таблицу. Схемы из символов не рисуй.
Для технических и абстрактных тем разбирай запись по частям слева направо и показывай шаги.
Если пишу «не понимаю», скажи то же проще, другими словами.
Заданий не давай, пока не попрошу.
В конце проверяй понимание 2–3 вопросами.
```

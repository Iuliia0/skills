# personalized-explanations

Скилл для ИИ-ассистента (Claude Code), который подбирает человеку формат объяснений, понятный именно ему, и выдаёт готовый текст личного профиля.

## Зачем

Два человека могут объяснять одно и то же, но одного понимаешь, а другого нет. Скилл не навязывает один «правильный» способ, а подбирает его вместе с человеком.

## Как это выглядит

1. **Опрос** на старте (6 вопросов): длина ответов, язык и термины, проверка понимания, реакция на «не понимаю», практика, интересы (по ним предлагаются темы).
2. **5 раундов.** В каждом новая тема (скилл сам предлагает логичные продолжения и советует выбирать темы из разных областей) и три коротких объяснения А, Б, В, которые отличаются одним: формат, порядок, размер, подача, реакция на непонимание. После раунда вопросы: что понятнее и почему, что непонятнее и почему, что бы изменил(а) в самом понятном.
3. **Итог:** «что я понял о тебе» и готовый профиль (до 10 строк, с условиями по типу темы, если выбор от неё зависел).
4. **Сохранение:** с согласия пользователя профиль записывается в `~/.claude/CLAUDE.md`, после чего действует во всех проектах. Если раздел «Как мне объяснять» там уже есть, скилл предлагает заменить его, а не добавляет второй. Тот же текст можно вставить в настройки персонализации других ассистентов.

## Установка (Claude Code)

```bash
git clone <адрес репозитория> ~/.claude/skills/personalized-explanations
```

Скилл запускается фразами вроде «подбери мне формат объяснений» или «персонализируй объяснения».

Черновик. Сценарий собран по итогам ручной сессии подбора объяснений (тема TypeScript), затем один раз пройден вручную (23.10.2026, темы по архитектуре), и по итогам прогона внесены 8 доработок. Как настоящий скилл через установку ещё не запускался, автоматических тестов нет.
